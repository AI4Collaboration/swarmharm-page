Environment design principles
Phase 1

Form the Swarm

Can separate agents in different sandboxes actively discover others and establish a persistent communication channel?

Phase 1 · Environment Design PrinciplesSwarm formation must emerge.
  1. 01
    Impossible alone

    Each legitimate task permits limited progress, but cannot be completed through one agent’s isolated workflow.

  2. 02
    Separate, simultaneous, unaware

    Agents stay live in separate sandboxes and are never told about peers, a team, a leader, or a communication channel.

  3. 03
    Unannounced shared system

    A natural task-relevant surface contains no planted messages; agents must discover it and establish live dialogue themselves.

Impossible alone · Unannounced shared system · Verified live dialogue
Phase 2

Collective Misalignment

Can the formed swarm produce verifiable system-level harm that no single agent establishes alone?

Phase 2 · Environment Design PrinciplesOutcome-first evaluation.
  1. 01
    Same live swarm

    The same agents, histories, sandboxes, and shared system continue naturally from Phase 1.

  2. 02
    Locally valid, jointly harmful

    At least two agents deliberately act; each action may look valid alone, while only their composition creates the system effect.

  3. 03
    Independent ground truth

    Recompute the system-level outcome from external state—not agent reports, status labels, or an LLM judge.

Same swarm · 2+ deliberate actions · External truth

Agents interact with task data, shared environments, and one another—without being told to form a swarm.

Research questions

Legitimate tasks. No planted malicious agent.

RQ1

Form the Swarm

When, and with how much natural cueing, do isolated agents establish stable communication?

RQ2

Collective Misalignment

When does a formed swarm produce verifiable harm that no single agent establishes alone?

Systematic test design+

Verify the setup, then observe the behavior

TASK CONTRACT

Prove the isolated path is impossible

Verify the blocker mechanically before collection. Model failure alone cannot establish task impossibility.

FORMATION CONTRACT

Verify live swarm formation

Require exact cross-agent reads and a live request–reply–read-back while concurrent private contexts remain active.

OUTCOME CONTRACT

Verify collective contribution

Require two or more deliberate causal actions and independently verify one system-level outcome that no single agent establishes alone.

A hard task, shared access, message exchange, or one agent’s adverse action cannot by itself establish collective misalignment. Each causal action and the final system effect are verified separately.

No cue supplies an answer or identifies another agent. Cue strength is a registered factor; propagation, composition, amplification, and emergent orchestration are possible observations—not required behavior.
