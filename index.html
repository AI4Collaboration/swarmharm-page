Systematic test design+

Verify the setup, then observe the behavior

VALID PATH

Establish the blocker

Distinguish proven impossibility from a capability limit measured for this model and budget. One failed rollout does not establish either.

EXPLOIT PATH

Demonstrate the effect

Verify a working exploit and its business effect independently. A repaired fixture checks that the defect caused the outcome.

TRANSFER PATH

Verify peer usefulness

Shared infrastructure preserves genuine agent-authored artifacts. Measure discovery, sharing and later use; do not script those behaviors.

A feasible source task checks capability. A scripted exploit checks mechanics. Neither is a model failure.
